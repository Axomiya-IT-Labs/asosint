# Project Overview

ASOSINT is an open-source Digital Trust platform focused on:

- OSINT
- Cybersecurity awareness
- AI literacy
- Deepfake detection
- Voice cloning awareness
- Online privacy
- Digital investigations
- Scam prevention
- Digital verification

The platform exists to help people verify information before trusting it.

Tagline:

> **Verify Before You Trust.**

---

# Development Philosophy

Every change should make the project:

- Faster
- Simpler
- More maintainable
- More accessible
- More scalable

Do not optimize for quick fixes.

Optimize for long-term maintainability.

# Core Principles

- Build once.
- Scale forever.
- Never rewrite architecture.
- Prefer reusable components.
- Prefer static rendering.
- Keep JavaScript minimal.
- Accessibility is mandatory.
- Performance is a feature.
- Privacy first.

---

# Performance Goals

Target:

- Lighthouse ≥ 95
- Fast page loads
- Minimal client-side JavaScript
- Optimized assets
- Excellent Core Web Vitals

---

# Localization

English and Assamese are first-class languages.

Do not introduce English-only features.

Every new feature should support localization.

---

# Before Making Changes

Always check:

- Can existing components be reused?
- Does this follow the design system?
- Does this maintain accessibility?
- Does this affect performance?
- Does this support bilingual content?
- Is documentation required?

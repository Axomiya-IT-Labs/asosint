# ASOSINT Design System

> Last Updated: August 2026

---

# Philosophy

ASOSINT is a Digital Trust platform.

The interface should communicate:

- Trust
- Clarity
- Professionalism
- Simplicity
- Speed

Users should immediately feel confident using the platform.

The UI should never look like a hacking website.

Avoid:

- Matrix aesthetics
- Neon green themes
- Skulls
- Hacker clichés
- Excessive glow
- Visual clutter

Instead, take inspiration from:

- Stripe
- Vercel
- GitHub
- Cloudflare
- Anthropic
- Linear
- Apple
- MDN Web Docs

---

# Design Principles

Every screen should follow these principles.

## Clear

Users should understand where they are immediately.

---

## Fast

The interface should feel lightweight.

No unnecessary animations.

No layout shifts.

---

## Accessible

Accessibility is a feature.

Never sacrifice readability.

---

## Consistent

Every page should feel like it belongs to the same product.

---

## Content First

Content is the product.

The interface should support the content, not compete with it.

---

# Theme

Dark mode is the default.

Light mode is fully supported.

Both themes must feel equally polished.
